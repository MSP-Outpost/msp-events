# Contributing

## Suggest an Event

Open an issue with the Suggest an Event form. Events are published on the [MSP Outpost events calendar](https://mspoutpost.com/community/events) first, then added here.

## Fix an Event

Dates and venues change. Open a Correction issue with a link to the organizer's page.

## Pull Requests

Keep the table sorted by start date and update `events.json` to match.

By contributing you agree to the [Code of Conduct](CODE_OF_CONDUCT.md) and to license your contribution under [CC BY 4.0](LICENSE).
